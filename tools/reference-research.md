# Reference Research
Use UI pattern libraries for interaction/structure and broader visual/cultural sources for art direction. Sources may include Mobbin, Refero, Are.na, Pinterest, studio case studies, archives, museums, photography, fashion, architecture, packaging, signage, film, industrial design and vernacular material.

For each selected reference capture: source, what is useful, underlying principle, what not to copy, and which direction it informs. Never make direct competitors the entire moodboard.
