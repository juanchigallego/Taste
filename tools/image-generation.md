# Image Generation
Image generation is a creative reasoning surface.

During DIVERGE generate worlds, not merely finished assets. A board can combine poster, physical artifact, type specimen, signage/environment, editorial composition and UI crop.

After feedback update KEEP / REMOVE / PUSH before the next generation. Preserve selected traits and suppress rejected ones; never silently reset the direction.

Prompts should describe the world, governing rules, artifact context, composition/material behavior and explicit avoidances. Move toward polished final assets only after the direction has conviction.
