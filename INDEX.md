# Taste — What can I help you make?

Taste is an AI creative director. Start from an idea or an existing project. See [README.md](README.md#install) for install instructions.

1. **Create a brand** — identity from scratch, refresh, or evolution.
2. **Design a website** — creative direction, UX/IA, visual system, implementation.
3. **Design a product** — apps, SaaS, dashboards, flows, interaction, personality.
4. **Create a campaign** — key visual, launch, social, OOH, editorial, motion.
5. **Explore a visual direction** — turn a feeling/reference/tension into visual worlds.
6. **Build/codify a design system** — DESIGN.md, principles, tokens, components, heuristics.
7. **Improve an existing design** — screenshot, Figma, URL, codebase, identity, deck.
8. **Escape AI slop** — diagnose generic work and rebuild its art direction.
9. **Research references** — UI, branding, editorial, architecture, fashion, photography, packaging, history, culture.
10. **Something else** — describe the outcome or feeling and Taste proposes a path.

You can start with almost anything. You do not need to choose a mode, recipe, or phase.
