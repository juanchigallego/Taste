# DISCOVER

Understand the real problem before aesthetics. Investigate purpose, audience, context, desired effect, equity, constraints, culture, category codes, personality and aversions. Ask few high-information questions. Output a short synthesis: what, for whom, desired effect, tensions, constraints, avoidances, unknowns. Gate: user recognizes the problem.

---

## Purpose
Establish what problem design needs to solve before any aesthetic work begins. DISCOVER prevents solving the wrong problem beautifully. Most "make it look better" requests hide an unstated strategic gap.

## Inputs
- User's initial request (often vague: "we need a rebrand", "make it feel premium")
- Any existing artifacts: product, website, deck, competitor links
- Known constraints: timeline, budget, legal, technical, brand equity to preserve
- Category context (if obvious)

## Steps

### 1. Inspect what exists
Before asking questions, look at what the user provided:
- Existing product/site/deck — what does it currently communicate?
- Competitor landscape — what does the category default to?
- User's language — what adjectives do they use? (Often meaningless until translated)

### 2. Ask few high-information questions
Prefer 2–4 sharp questions over a questionnaire. Target unknowns that would change the creative direction:

| If unclear about... | Ask something like... |
|---------------------|----------------------|
| Audience | "Who needs to trust this in the first 10 seconds—and what would make them leave?" |
| Desired effect | "After someone interacts with this, what should they *feel* or *do* differently?" |
| Differentiation | "What do competitors all look like? What would be wrong to copy?" |
| Constraints | "What's non-negotiable—existing logo, colors, legal claims, tech stack?" |
| Aversions | "What visual territory feels completely wrong for this?" |
| Success | "What would make you say 'yes, that's us' vs 'close but not quite'?" |

Translate vague adjectives immediately:
- "Premium" → exclusive? luxurious? expensive-looking? high-quality craft?
- "Modern" → contemporary? minimal? tech-forward? not dated?
- "Professional" → credible? corporate? restrained? expert?

### 3. Map category codes and gaps
Identify what the category expects (conventions) and where differentiation might live:
- What does every competitor do visually?
- What would feel "off" if missing?
- What clichés should be avoided?

### 4. Identify productive tensions
Name 1–2 tensions the brand/product must hold:
- Technical ↔ human
- Premium ↔ accessible
- Established ↔ disruptive
- Local ↔ global

These become seeds for POSITION.

### 5. Synthesize
Produce a short discovery document. User must recognize themselves in it.

## Output shape
```
## Discovery: [project name]

**What:** [one sentence — what is this?]
**For whom:** [primary audience + what they need]
**Desired effect:** [what should change in the viewer/user]
**Productive tensions:** [2 tensions to hold]
**Category codes:** [what's expected in this space]
**Differentiation opportunity:** [where the gap is]
**Constraints:** [hard limits]
**Avoidances:** [what user explicitly rejects]
**Unknowns:** [what still needs resolution — flag for POSITION]
**Recommended next step:** [POSITION / REFERENCE if brief is already clear]
```

## Quality gates
- [ ] User recognizes the problem statement ("yes, that's what we're solving")
- [ ] Vague adjectives translated to observable behavior
- [ ] At least one productive tension named
- [ ] Constraints and avoidances documented
- [ ] Did not jump to visual solutions

## Anti-patterns
- **Questionnaire dump**: 15 questions when 3 would suffice
- **Assumption leap**: Inferring audience/position without checking
- **Aesthetic-first**: "What colors do you like?" before understanding the problem
- **Competitor copying**: Treating competitor research as the brief
- **Vague synthesis**: "A modern brand for professionals" (not actionable)

## Good vs bad discovery one-liners

**Bad:** "They want a modern, clean brand for their SaaS product"
**Good:** "B2B soil testing platform for agronomists who distrust flashy ag-tech marketing—they need to feel the product was built by people who understand farming"

**Bad:** "Make it look more premium"
**Good:** "Translate 'premium' → restrained confidence, not luxury gloss. Audience is enterprise buyers who equate polish with credibility but reject pretension"

## When to stop
- User confirms the synthesis
- Enough clarity to write a creative thesis (→ POSITION)
- Or: brief is already sharp and discovery confirms it (→ POSITION or REFERENCE)

## When to route elsewhere
- User provides strong thesis already → skip to POSITION (validate) or REFERENCE
- Discovery reveals no real problem / pure execution request → APPLY (with CRITIQUE)
- User only wants a disposable sketch → APPLY with minimal discovery, flag limitations
