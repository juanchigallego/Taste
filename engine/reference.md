# REFERENCE

Discover visual/cultural territory and underlying principles. Include adjacent/non-obvious domains. Label each reference by why it matters: typography, composition, imagery, materiality, interaction, artifacts, pacing, culture. Separate inspiration, convention and cliché. Gate: research makes the thesis concrete while opening multiple directions.

---

## Purpose
Build a territory of visual and cultural references that could inform the design direction. REFERENCE is research—finding evidence of how ideas have been expressed visually and extracting principles, not copying surfaces.

## Inputs
- Creative thesis from POSITION
- Any existing references user has provided
- Domain/category context (but don't limit to category)

## Steps

### 1. Map the obvious territory first
Start with direct category references (what competitors/peers do), but label them clearly:
- **Convention**: Everyone does this, audience expects it
- **Cliché**: Overused, signals laziness
- **Differentiation opportunity**: Gap in what exists

### 2. Expand to adjacent and non-obvious domains
This is where distinctiveness comes from. For each thesis concept, ask: where else has this idea been expressed?

| If the thesis involves... | Look at... |
|---------------------------|------------|
| Authority without coldness | Academic publishing, museum identity, legal ephemera |
| Playfulness with credibility | Science museums, educational toys, vintage technical illustration |
| Luxury without pretension | Japanese craft, Scandinavian design, boutique hospitality |
| Technology with warmth | Medical devices, kitchen appliances, Braun/Muji |
| Speed and precision | Racing, aviation, sports broadcasting, logistics |
| Handmade at scale | Letterpress, risograph, artisan food packaging |

Search: editorial design, architecture, fashion, industrial design, packaging, signage, art direction, film titles, interface history, print ephemera, vernacular culture.

### 3. Label each reference by principle
Don't collect images—collect principles. For each reference, document:
- **Source**: What/who/where
- **Relevance**: Why this matters for the thesis
- **Principle**: What can be extracted and applied (not copied)
- **Category**: typography, composition, color, imagery, materiality, interaction, artifacts, pacing, culture

**Bad reference note:** "Cool poster, nice colors"
**Good reference note:** "Swiss pharmaceutical packaging, 1970s — Relevance: 'precision + humanity' thesis. Principle: Technical information can feel caring through generous white space and soft-edged illustration. Category: composition, imagery."

### 4. Separate inspiration from cliché
Flag references that are:
- **Fresh territory**: Not commonly referenced in this category
- **Shared inspiration**: Others in category use this too (use carefully)
- **Cliché source**: Referencing this will feel derivative (avoid surface)

### 5. Create reference clusters
Group references that support different interpretations of the thesis. These clusters become seeds for DIVERGE:
- "Cluster A: Academic precision (archives, specimen, catalog)"
- "Cluster B: Warm institution (museum, library, public service)"
- "Cluster C: Vernacular expertise (trade manuals, technical illustration)"

### Ready for DIVERGE?

## Quality gates
- [ ] Looked beyond direct category
- [ ] Each reference has an extracted principle
- [ ] References labeled (fresh/shared/cliché)
- [ ] Multiple clusters that interpret thesis differently
- [ ] Principles, not surfaces, documented

## Anti-patterns
- **Pinterest syndrome**: Collecting "nice" images without principles
- **Category-only**: Only looking at competitors
- **Surface copying**: Referencing Stripe means "copy Stripe's gradients"
- **Reference as solution**: "Just do what X did" (skips DIVERGE/SELECT)
- **Quantity hoarding**: 100 references with no synthesis

## When to route elsewhere
- References reveal thesis is too vague → POSITION
- Have enough territory → DIVERGE
- References show the problem is misunderstood → DISCOVER
- User provides strong references → skip to DIVERGE with their territory
